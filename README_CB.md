# Audio vs. Audio & Video Guidance for Coherent Breathing: A Single-Subject EEG Study

An open protocol and a set of findings comparing two ways of guiding coherent breathing (6 s inhale / 6 s exhale, 5 breaths per minute): **audio only** and **audio with a synchronized visual animation**. Brain activity was recorded with a 14-channel Emotiv EPOC X.

This is a single-subject self-experiment (N \= 1), shared openly so others can read it, reuse the stimuli, and run their own version.

## The study at a glance

* **Question:** Does adding a visual pacing cue change the neural and affective response to guided coherent breathing?  
* **Design:** Within-subject. Each session had a 240 s eyes-open baseline, then a 5-minute audio & video block, then a 5-minute audio-only block. Eyes stayed open throughout. Three sessions.  
* **Equipment:** Emotiv EPOC X (14 channels, saline sensors), Emotiv Studio for Performance Metrics, Logic Pro for the audio, TouchDesigner for the visuals.  
* **Outcome measures:** Emotiv Performance Metrics (Stress, Attention, Engagement, Excitement, Interest), baseline-corrected, plus band power, topographic maps, and frontal alpha asymmetry.

### **Headline results (from Emotiv Studio's insights report)**

Change from the pre-meditation baseline:

| Metric | Audio & Video | Audio |
| ----- | ----- | ----- |
| Stress | −26.99 | \+0.52 |
| Engagement | \+12.85 | \+4.78 |
| Excitement | −19.39 | −5.58 |
| Interest | −14.85 | −1.77 |
| Attention | \+2.25 | \+1.80 |

Audio & Video was associated with lower stress and excitement and higher engagement, along with a larger drop in interest. Full results, figures, and discussion are in the [write-up](https://github.com/b-neuroch/coherent-breathing-eeg/blob/main/WRITEUP_CB.md).

## About this project

This is a personal research project, not a clinical or peer-reviewed study. It has one participant, who is also the experimenter, and the reported values are the ones generated by Emotiv Studio's own insights report. Condition order was fixed (audio & video always first), so order and modality cannot be separated. The temporal-prediction idea in the write-up (that the visual cue helps by letting you anticipate when each breath phase ends) came up during the sessions, not before them, so it is a hypothesis for future testing. The protocol is written so that others can reproduce the setup independently, ideally with condition order randomized.
